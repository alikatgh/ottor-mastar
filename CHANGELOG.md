# Changelog

## 1.1.0 — submitted 2026-09-27

- Android uses the same Sardaana lily artwork as the current iOS app, with adaptive launcher sizes that keep the flower inside the safe area.
- Carries forward the botanical-only Android beta changes and targets Android API 36.
- Refreshes the bundled catalog and public news from the current project data.
- The website news feed now includes Android tester instructions; the Android News tab fetches updates when online and retains its bundled fallback offline.
- Adds Google Group enrollment and Play opt-in instructions to the app download page and README.

Signed version code 4 is available to internal testers (September 27 at 12:07 local time). The same 1.1.0 build, updated 53-plant listing, lily icon, feature graphic and four genuine phone screenshots are now in closed-beta review.

## 1.0.1 — submitted 2026-09-27

- Signed Android beta uploaded to Google Play (version code 3).
- Includes the illustrated botanical catalog, search, favorites and reading settings.
- Removes medicinal-use sections and remedy wording from Android; the beta is a botanical reference.
- Bundled catalog works offline; full-resolution images and external resources require internet.
- Closed testing uses the `ottormastar-android-testers` Google Group.

Closed beta version code 3 is approved and available to selected testers; the newer build 4 is in review. Join the group with your Android Google account, then opt in on Play. This is not an unrestricted open test or a public production release. Google requires at least 12 testers opted in continuously for 14 days before an application for production access.
